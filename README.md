# Carrito de compras

El proyecto está construido sobre una arquitectura basada en componentes utilizando el ecosistema de React. El código fuente emplea TypeScript para proporcionar un tipado estático robusto, reduciendo errores en tiempo de ejecución. La compilación y el entorno de desarrollo están potenciados por Vite, asegurando un empaquetado (bundling) eficiente y tiempos de respuesta rápidos.
